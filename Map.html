About the Map

The Christchurch Fruit Trail map is a collection of all the publically accessible Fruit Trees in the area. Sourced from Christchurch City Council Data this map is an accurate representation for foraging locations in the area. All locations are either stored in clusters or displayed with an Icon that has been diferently colour coded based on the tree. Trees can be filtered for a particar Tree tpye, and directions can be routed from your current IP address. Please see the tutorial for further instructions on how to use the interactive Fruit Trail Map
